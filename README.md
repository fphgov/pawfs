Utility package for accessing files from our pipelines. (Miau &amp; Ráció)


A robot using the auth scheme shown in sharepoint_client_access.py needs a Confidential Client app registration.
And Sites.ReadWrite.All or similar permission for msgraph! 
    (not sharepoint: that can not really be reached by robots any more.)
